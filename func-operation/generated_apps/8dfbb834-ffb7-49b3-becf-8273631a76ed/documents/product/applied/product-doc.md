# 教师管理 产品需求文档

## 1. 业务目标

- 为教务/人事管理人员提供一个集中的教师信息管理工具，可维护教师档案、掌握每位教师的在职状态，并完成入职建档、信息更新、停用、离职等状态流转。
- 让管理人员能快速检索教师、按院系和状态筛选，避免"有多少教师、谁在哪个院系、哪些人在职/停用/离职"只能靠线下表格或口头询问。
- 保证每次新增、编辑、状态流转都有明确反馈，误操作可通过状态流转与删除限制被约束。

## 2. 目标用户与使用场景

- 目标用户：教务管理员 / 人事管理人员（内部运营工具，非面向教师本人的自助端）。
- 使用场景：
  - 新教师入职，管理员录入教师档案，填写姓名、工号、所属院系、职称等信息。
  - 教师信息变更（电话、邮箱、职称、院系调动）时，管理员编辑并保存。
  - 教师请假、借调或暂停授课时，管理员将记录"停用"，不再参与排课与教学。
  - 教师离职、退休时，管理员将记录"离职"，档案保留但标记为不再在职。
  - 想确认某教师是否在职、联系方式、所属院系时，通过搜索和筛选快速定位。

## 3. 核心流程

**主流程（教师建档 → 信息维护 → 状态流转）**

```text
打开功能 -> 查看教师列表 -> 点击"新建教师" -> 填写表单并保存 -> 列表出现新记录
-> 选择记录点击"编辑" -> 修改电话/邮箱/职称等信息 -> 保存 -> 列表字段刷新
-> 选择记录点击"停用/在职"或"离职" -> 二次确认 -> 状态更新 -> 列表更新
```

**恢复路径 1（表单校验失败）**

```text
新建/编辑时提交缺少必填项或工号格式非法的表单 -> 页面标红对应字段并提示原因
-> 修正后再次提交 -> 保存成功
```

**恢复路径 2（工号重复被拦截）**

```text
新建或编辑时录入已存在的工号 -> 页面提示"工号已存在，请检查"
-> 修改工号后重新提交 -> 保存成功
```

**恢复路径 3（删除在职教师被拦截）**

```text
选择状态为"在职"的教师执行删除 -> 页面拦截并提示"在职教师不可删除，请先办理离职"
-> 先将该教师流转为"离职"再执行删除 -> 删除成功
```

## 4. 核心页面

### 4.1 教师列表（工作台主页面）

- 布局：顶部功能标题 + 操作区，下方筛选栏，主体为紧凑型表格工作区。
- 主操作：右上角"新建教师"按钮。
- 次要操作：搜索、院系筛选、国籍筛选、状态筛选、刷新、分页；行内"详情 / 编辑 / 在职·停用 / 离职 / 删除"。
- 必见表字段：姓名、工号、所属院系、职称、联系电话、电子邮箱、状态、入职日期、最近更新时间。
- 空状态：无任何教师记录时，表格区域显示"暂无教师"，并展示"新建教师"入口。
- 错误状态：列表加载失败时，显示错误提示与"重试"按钮。

### 4.2 新建 / 编辑教师表单（弹窗）

- 布局：居中弹窗表单，字段按"基本信息 / 联系方式 / 任职信息"分组。
- 主操作："保存"；次要操作："取消"。
- 必填字段：姓名、工号、所属院系、联系电话；性别、出生日期、学历、职称、电子邮箱、入职日期为可填写/可选项。
- 国籍：下拉单选，选项不写死在本功能内，统一读取已有的全局配置键 `country` 提供的选项列表（value/label）。
- 校验错误：缺失或非法时在对应字段下方红字提示。
- 空状态 / 错误状态：不适用（表单型弹窗，统一走字段校验与提交失败提示）。

### 4.3 教师详情（详情面板）

- 布局：从列表点击"详情"打开右侧详情面板或弹窗。
- 主操作：根据当前状态显示"编辑 / 在职·停用 / 离职 / 删除"。
- 展示字段：姓名、工号、国籍、性别、出生日期、学历、所属院系、职称、联系电话、电子邮箱、入职日期、状态、最近更新时间。
- 空状态 / 错误状态：不适用（详情读取失败时显示错误提示与"重试"）。

## 5. 关键字段或业务对象

| 对象 | 字段 | 说明 |
| --- | --- | --- |
| 教师 | 姓名 | 教师姓名，必填，用于列表展示与检索 |
| 教师 | 工号 | 唯一工号，必填，用于唯一标识与检索；不可重复 |
| 教师 | 国籍 | 国籍，可选，下拉单选；选项由已有的全局配置键 `country` 提供，本功能不内置国籍列表，用于档案展示与筛选 |
| 教师 | 性别 | 性别（男 / 女），用于档案展示 |
| 教师 | 出生日期 | 出生日期，用于档案展示 |
| 教师 | 学历 | 学历（如本科、硕士、博士），用于档案展示与筛选 |
| 教师 | 所属院系 | 所属院系/部门，必填，用于列表展示与筛选 |
| 教师 | 职称 | 职称（如讲师、副教授、教授），用于档案展示与筛选 |
| 教师 | 联系电话 | 联系电话，必填，用于联系与检索 |
| 教师 | 电子邮箱 | 电子邮箱，用于联系 |
| 教师 | 入职日期 | 入职日期，用于档案展示与排序 |
| 教师 | 状态 | 在职 / 停用 / 离职；由状态流转操作维护，不可直接编辑 |
| 教师 | 最近更新时间 | 记录最近一次增删改或状态流转时间 |

**状态说明**

- 在职：教师正常在岗，可正常参与排课与教学，可执行停用或离职。
- 停用：教师暂停参与排课与教学（如请假、借调、暂停授课），可执行恢复在职或离职。
- 离职：教师已离开学校，档案保留但不再在职，可执行删除归档。

**全局配置约定（国籍）**

- 国籍下拉选项统一来自全局公共配置，复用已有的配置键 `country`，值为选项数组，每项包含 `value` 与 `label`。
- 本功能在新建/编辑表单与筛选栏读取该配置渲染下拉；不内置、不写死国籍选项。
- 全局配置由具备配置权限的管理员维护，本功能只读取；配置更新后，下拉选项即时生效，历史记录的国籍值保持不变。

## 6. 关键操作与按钮

| 操作 | 触发 | 输入 | 成功反馈 | 失败反馈 | 权限要求 |
| --- | --- | --- | --- | --- | --- |
| 新建教师 | 列表右上角"新建教师" | 姓名、工号、所属院系、联系电话等表单字段 | 弹窗关闭，列表出现新记录 | 字段标红提示；保存失败显示错误提示 | 受控 |
| 编辑教师 | 行内/详情"编辑" | 可修改的表单字段 | 弹窗关闭，列表字段刷新 | 字段标红提示；保存失败显示错误提示 | 受控 |
| 停用 | 行内/详情"停用" | 二次确认 | 状态变为停用，列表更新 | 操作失败显示错误提示 | 受控 |
| 恢复在职 | 行内/详情"在职" | 二次确认 | 状态恢复为在职，列表更新 | 操作失败显示错误提示 | 受控 |
| 离职 | 行内/详情"离职" | 二次确认 | 状态变为离职，列表更新 | 操作失败显示错误提示 | 受控 |
| 删除 | 行内/详情"删除" | 二次确认 | 记录从列表移除 | 在职教师被拦截，提示先办理离职 | 受控 |
| 搜索 | 筛选栏搜索框 | 姓名 / 工号 / 联系电话关键词 | 列表按关键词过滤 | 无结果时显示空结果与清除入口 | 非受控 |
| 筛选 | 筛选栏院系、国籍、状态、学历、职称选择 | 对应筛选值 | 列表按条件过滤 | 无结果时显示空结果与清除入口 | 非受控 |
| 查看详情 | 行内"详情" | 无 | 打开详情面板 | 读取失败显示错误提示 | 非受控 |
| 刷新 / 分页 | 筛选栏刷新按钮 / 分页控件 | 无 | 列表刷新或翻页 | 加载失败显示错误提示与重试 | 非受控 |

**权限规则说明**

- 新建、编辑、删除、停用、恢复在职、离职均改变业务状态，为"受控按钮"，需纳入按钮级权限控制。
- 搜索、筛选、查看详情、刷新、分页为只读操作，属于"非受控操作"，默认对所有可访问用户可见，无需单独按钮权限。

## 7. 页面状态与异常恢复

- 加载中：列表加载时显示加载占位；新建/编辑/状态流转提交时按钮进入 loading 并禁止重复点击。
- 空数据：无教师记录时显示"暂无教师"与"新建教师"入口；筛选无结果时显示"没有符合条件的教师"与"清除筛选"入口。
- 表单校验错误：必填缺失、工号格式非法、联系电话格式非法时，在对应字段下方红字提示，阻止提交。
- 业务校验失败：工号已存在、删除在职教师、对已离职教师再次操作状态时，给出明确提示，数据不做修改。
- 后端/保存失败：新增、编辑、删除或状态流转失败时，弹 toast 显示失败原因，保留当前填写内容或列表状态，允许重试。
- 无权限：当用户缺少某受控按钮权限时，对应按钮不显示或置灰；只读操作始终可用。
- 全局配置加载失败：国籍下拉读取全局配置失败或配置键不存在时，下拉显示"选项加载失败"并提供重试，阻止提交国籍但允许暂存其它字段；不因配置异常阻断整个表单保存流程。
- 可恢复下一步：所有失败提示后均保留原页面状态，用户可修正输入、清除筛选或重试，不出现死页面。

## 8. 标准样式与布局约束

- 采用 func-operation 生成应用的统一内部工具样式：顶部标题区 + 工具栏 + 内容区 + 弹窗/详情面板 + toast/alert 反馈。
- 中性灰底、蓝色主操作按钮；紧凑型表格与表单布局。
- 状态字段使用标签展示（在职 / 停用 / 离职），便于快速识别。
- 统一加载、空、错误、校验、无权限状态样式，不自定义品牌化或营销化视觉。
- 具体尺寸与色值由技术设计与生成应用阶段按共享样式规范落地，本文档不定义精确 CSS。

## 9. 范围边界与不做内容

- 本次范围：教师档案维护、院系/学历/职称等基础字段管理、在职/停用/离职状态流转、检索与筛选。
- 不做内容：
  - 不建立排课、课表、授课班级等教学业务关联。
  - 不记录考勤、请假审批、薪酬福利等人事流程。
  - 不生成教师入职/离职审批单，不与其他系统联动。
  - 不做批量导入/导出、账号开通、权限分配等扩展能力。
  - 不做面向教师本人的自助查询与信息修改页面。

## 10. 验收标准

- 用户可以新建一条教师记录，保存后列表立即出现该记录，并可打开详情查看完整字段。
- 用户提交缺少必填字段或工号格式非法的表单时，页面在对应字段下方显示具体错误，且不产生新记录。
- 用户录入重复工号时，页面明确提示"工号已存在"并阻止保存。
- 用户执行停用、恢复在职、离职后，状态标签正确切换并同步到列表。
- 用户删除状态为"在职"的教师时，页面拦截并提示先办理离职；转为离职后可正常删除。
- 用户搜索或筛选不存在的关键词/条件时，页面显示空结果与"清除筛选"入口。
- 新建、编辑、删除、停用、恢复在职、离职按钮均受权限控制；搜索、筛选、详情、刷新、分页默认可见可用。

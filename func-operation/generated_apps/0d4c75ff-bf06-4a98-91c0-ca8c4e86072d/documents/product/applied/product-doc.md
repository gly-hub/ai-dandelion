# 图书管理 产品需求文档

## 1. 业务目标

- 为图书运营/馆藏管理员提供一个集中的图书管理工具，可维护图书档案、跟踪每种图书的总库存与可借数量，并完成借出、归还、下架等状态流转。
- 让管理员能快速检索图书、掌握在馆与借出情况，避免"有哪些书、还剩几本可借"只能靠线下表格或口头询问。
- 保证每次新增、编辑、借出、归还都有明确反馈，误操作可通过状态流转与删除限制被约束。

## 2. 目标用户与使用场景

- 目标用户：图书管理员 / 馆藏运营人员（内部运营工具，非面向读者的自助端）。
- 使用场景：
  - 新到一批书，管理员录入图书档案，录入每本书的总库存。
  - 读者借书时，管理员在图书记录上执行"借出"，可借数量减少。
  - 读者还书时，管理员执行"归还"，可借数量恢复。
  - 图书破损、淘汰时，管理员将记录"下架"或"删除"，停止对外借出。
  - 想确认某本书是否还有库存、放在哪里时，通过搜索和筛选快速定位。

## 3. 核心流程

**主流程（图书新增 → 借出 → 归还）**

```text
打开功能 -> 查看图书列表 -> 点击"新建图书" -> 填写表单并保存 -> 列表出现新记录
-> 选择记录点击"借出" -> 输入借出数量 -> 可借数量减少 -> 状态更新
-> 选择记录点击"归还" -> 输入归还数量 -> 可借数量恢复 -> 状态更新
```

**恢复路径 1（表单校验失败）**

```text
新建/编辑时提交缺少必填项或数量为 0 的表单 -> 页面标红对应字段并提示原因
-> 修正后再次提交 -> 保存成功
```

**恢复路径 2（借出数量超出可借）**

```text
对可借数量不足的图书执行借出 -> 提交数量 > 可借数量 -> 页面提示"超出可借数量"
-> 调整数量或取消 -> 回到原列表，数据未被修改
```

**恢复路径 3（删除被借出的图书被拦截）**

```text
选择尚有借出数量的图书执行删除 -> 页面拦截并提示"存在借出记录，请先归还"
-> 执行归还后再删除 -> 删除成功
```

## 4. 核心页面

### 4.1 图书列表（工作台主页面）

- 布局：顶部功能标题 + 操作区，下方筛选栏，主体为紧凑型表格工作区。
- 主操作：右上角"新建图书"按钮。
- 次要操作：搜索、分类筛选、状态筛选、刷新、分页；行内"详情 / 编辑 / 借出 / 归还 / 下架·上架 / 删除"。
- 必见表字段：书名、ISBN、作者、分类、馆藏位置、总库存、可借数量、状态、最近更新时间。
- 空状态：无任何图书记录时，表格区域显示"暂无图书"，并展示"新建图书"入口。
- 错误状态：列表加载失败时，显示错误提示与"重试"按钮。

### 4.2 新建 / 编辑图书表单（弹窗）

- 布局：居中弹窗表单，字段按"基础信息 / 库存信息"分组。
- 主操作："保存"；次要操作："取消"。
- 必填字段：书名、ISBN、总库存；其余字段可填写。
- 校验错误：缺失或非法时在对应字段下方红字提示。
- 空状态 / 错误状态：不适用（表单型弹窗，统一走字段校验与提交失败提示）。

### 4.3 图书详情（详情面板）

- 布局：从列表点击"详情"打开右侧详情面板或弹窗。
- 主操作：根据当前状态显示"编辑 / 借出 / 归还 / 下架·上架 / 删除"。
- 展示字段：书名、ISBN、作者、分类、出版社、出版年份、馆藏位置、总库存、可借数量、借出数量、状态、最近更新时间。
- 空状态 / 错误状态：不适用（详情读取失败时显示错误提示与"重试"）。

## 5. 关键字段或业务对象

| 对象 | 字段 | 说明 |
| --- | --- | --- |
| 图书 | 书名 | 图书名称，必填，用于列表展示与检索 |
| 图书 | ISBN | 国际标准书号，必填，用于唯一标识与检索 |
| 图书 | 作者 | 作者姓名，用于展示与检索 |
| 图书 | 分类 | 图书分类（如文学、科技、历史），用于筛选 |
| 图书 | 出版社 | 出版单位 |
| 图书 | 出版年份 | 出版年份，用于筛选排序 |
| 图书 | 馆藏位置 | 存放位置（如 A区-3排），便于找书 |
| 图书 | 总库存 | 该图书的馆藏总数，必填，不小于 0 |
| 图书 | 借出数量 | 当前已借出数量，不可直接编辑，由借出/归还操作增减 |
| 图书 | 可借数量 | 可借数量 = 总库存 - 借出数量，系统计算展示 |
| 图书 | 状态 | 在馆 / 借出 / 下架；借出数量为 0 且在馆时为"在馆"，借出数量大于 0 时为"借出"，下架时为"下架" |
| 图书 | 最近更新时间 | 记录最近一次增删改或状态流转时间 |

**状态说明**

- 在馆：可借数量大于 0，可执行借出。
- 借出：可借数量等于 0（全部借出），可执行归还。
- 下架：记录不再对外可借，即使有可借数量也不允许借出，可执行上架恢复。

## 6. 关键操作与按钮

| 操作 | 触发 | 输入 | 成功反馈 | 失败反馈 | 权限要求 |
| --- | --- | --- | --- | --- | --- |
| 新建图书 | 列表右上角"新建图书" | 书名、ISBN、总库存等表单字段 | 弹窗关闭，列表出现新记录 | 字段标红提示；保存失败显示错误提示 | 受控 |
| 编辑图书 | 行内/详情"编辑" | 可修改的表单字段 | 弹窗关闭，列表字段刷新 | 字段标红提示；保存失败显示错误提示 | 受控 |
| 借出 | 行内/详情"借出" | 借出数量（默认 1） | 可借数量减少，状态更新，出现成功提示 | 超出可借数量或被下架时拦截提示 | 受控 |
| 归还 | 行内/详情"归还" | 归还数量（默认 1） | 可借数量恢复，状态更新，出现成功提示 | 归还数量大于借出数量时拦截提示 | 受控 |
| 下架 | 行内/详情"下架" | 二次确认 | 状态变为下架，列表更新 | 操作失败显示错误提示 | 受控 |
| 上架 | 行内/详情"上架" | 二次确认 | 状态恢复为在馆/借出，列表更新 | 操作失败显示错误提示 | 受控 |
| 删除 | 行内/详情"删除" | 二次确认 | 记录从列表移除 | 存在借出数量时拦截，提示先归还 | 受控 |
| 搜索 | 筛选栏搜索框 | 书名 / ISBN / 作者关键词 | 列表按关键词过滤 | 无结果时显示空结果与清除入口 | 非受控 |
| 筛选 | 筛选栏分类、状态选择 | 分类 / 状态值 | 列表按条件过滤 | 无结果时显示空结果与清除入口 | 非受控 |
| 查看详情 | 行内"详情" | 无 | 打开详情面板 | 读取失败显示错误提示 | 非受控 |
| 刷新 / 分页 | 筛选栏刷新按钮 / 分页控件 | 无 | 列表刷新或翻页 | 加载失败显示错误提示与重试 | 非受控 |

**权限规则说明**

- 新建、编辑、删除、借出、归还、下架、上架均改变业务状态，为"受控按钮"，需纳入按钮级权限控制。
- 搜索、筛选、查看详情、刷新、分页为只读操作，属于"非受控操作"，默认对所有可访问用户可见，无需单独按钮权限。

## 7. 页面状态与异常恢复

- 加载中：列表加载时显示加载占位；新建/编辑/借出/归还提交时按钮进入 loading 并禁止重复点击。
- 空数据：无图书记录时显示"暂无图书"与"新建图书"入口；筛选无结果时显示"没有符合条件的图书"与"清除筛选"入口。
- 表单校验错误：必填缺失、ISBN 格式非法、总库存为 0 或负、借出/归还数量为 0 或非整数时，在对应字段下方红字提示，阻止提交。
- 业务校验失败：借出数量超出可借数量、对被下架图书借出、归还数量超出借出数量时，给出明确提示，数据不做修改。
- 后端/保存失败：新增、编辑、删除或状态流转失败时，弹 toast 显示失败原因，保留当前填写内容或列表状态，允许重试。
- 无权限：当用户缺少某受控按钮权限时，对应按钮不显示或置灰；只读操作始终可用。
- 可恢复下一步：所有失败提示后均保留原页面状态，用户可修正输入、清除筛选或重试，不出现死页面。

## 8. 标准样式与布局约束

- 采用 func-operation 生成应用的统一内部工具样式：顶部标题区 + 工具栏 + 内容区 + 弹窗/详情面板 + toast/alert 反馈。
- 中性灰底、蓝色主操作按钮；紧凑型表格与表单布局。
- 状态字段使用标签展示（在馆 / 借出 / 下架），便于快速识别。
- 统一加载、空、错误、校验、无权限状态样式，不自定义品牌化或营销化视觉。
- 具体尺寸与色值由技术设计与生成应用阶段按共享样式规范落地，本文档不定义精确 CSS。

## 9. 范围边界与不做内容

- 本次范围：图书档案维护、库存数量管理、借出/归还状态流转、下架/上架、检索与筛选。
- 不做内容：
  - 不建立独立"读者档案"，不记录借阅人身份。
  - 不生成借阅流水台账、不统计逾期与罚款。
  - 不做批量导入/导出、条码打印、预约提醒等扩展能力。
  - 不做面向读者的自助查询与在线借还页面。

## 10. 验收标准

- 用户可以新建一条图书记录，保存后列表立即出现该记录，并可打开详情查看完整字段。
- 用户提交缺少必填字段或数量非法的表单时，页面在对应字段下方显示具体错误，且不产生新记录。
- 用户执行借出后，可借数量按输入值减少，状态在"在馆/借出"间正确切换；归还后数量恢复。
- 用户对可借数量不足或被下架的图书执行借出时，页面明确提示并阻止操作，数据不被修改。
- 用户删除尚有借出数量的图书时，页面拦截并提示先归还；归还后可正常删除。
- 用户搜索或筛选不存在的关键词/条件时，页面显示空结果与"清除筛选"入口。
- 新建、编辑、删除、借出、归还、下架、上架按钮均受权限控制；搜索、筛选、详情、刷新、分页默认可见可用。
